## 🛠️ Requirements

- Python 3
- pandas
- matplotlib
- numpy
- Jupyter Notebook, or VS Code with the Jupyter extension

Install the libraries with:

```
pip install pandas matplotlib numpy
```

## 📖 Pandas Basics

`pandas_basics.ipynb` covers the basics of pandas using `orders.csv`: reading a CSV file, viewing data with `head()`, `tail()`, `info()` and `describe()`, selecting columns, filtering rows, updating values, and dropping rows and missing values.

## 📊 Matplotlib Basics

`matplotlib.ipynb` covers data visualization with Matplotlib:

- Line plots with different markers, line styles, colors and line widths
- Adding a grid with `grid()`
- Bar chart
- Pie chart
- Scatter plot
- Histogram
- Subplots
